BUILD APK (khong can cai Android Studio)
1. Tao repo GitHub moi (private cung duoc), upload TOAN BO thu muc nay (gom .github).
2. Tab Actions > "Build APK" chay xong (~4 phut) > tai artifact "NenVN30F1M-apk" > giai nen ra app-debug.apk.
3. Chep apk vao dien thoai, cai (cho phep "cai tu nguon khong ro").

DUNG
- PC: chep ticker_server.py moi (HOST=0.0.0.0), chay chay.bat. Cho phep Python qua Windows Firewall (mang Private).
- PC va dien thoai cung WiFi. Tren PC: ipconfig -> IPv4, vd 192.168.1.10.
- Mo app, lan dau hien hop thoai: nhap ws://192.168.1.10:8765
- Doi dia chi sau nay: cham cham tron (trang thai ket noi) o header.
